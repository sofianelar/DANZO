# DANZO MEN — متجر ملابس رجالية (نسخة بداية)

## المتطلبات
- تثبيت Node.js من https://nodejs.org
- اتصال إنترنت عند أول تثبيت للحزم، ولتحميل صور Unsplash والخط.

## التشغيل على Windows
1. فك ضغط الملف.
2. افتح المجلد `danzo_men_store` في Visual Studio Code.
3. انسخ `.env.example` وسمّي النسخة `.env`.
4. افتح `.env` وبدّل `ADMIN_PASSWORD` بكلمة سر قوية و`SESSION_SECRET` بسلسلة طويلة عشوائية.
5. في Terminal داخل المجلد شغّل:
   `npm install`
6. ثم شغّل:
   `npm start`
7. افتح `http://localhost:3000`

## لوحة المسؤول
في نفس الموقع انزل إلى "لوحة المسؤول"، ثم سجّل بكلمة السر التي وضعتها في `.env`.
تقدر تضيف المنتجات وتغيّر الاسم والسعر والصنف والمقاسات ورابط الصورة، وتراجع الطلبات وتغيّر حالتها.

## ملاحظات مهمة
- الطلبات والمنتجات تُحفظ محليًا في مجلد `data` على الجهاز الذي يشغّل السيرفر.
- هذا مشروع بداية للتجربة وليس جاهزًا مباشرة لاستعمال تجاري عام. قبل نشره للزبائن، استعمل استضافة HTTPS، قاعدة بيانات دائمة، حماية أقوى لتسجيل المسؤول ومعدل محاولات الدخول، نسخًا احتياطية، وسياسة خصوصية وشروط البيع.
- لا تضع كلمات السر في ملفات الواجهة أو تشارك ملف `.env`.
- صور المنتجات الحالية أمثلة؛ استبدلها بصور حقيقية تملك حق استعمالها.
- توصيل الطلبات والدفع لا يتكفل بهما الموقع تلقائيًا؛ يلزم الاتفاق مع شركة توصيل ومتابعة الطلبات.
